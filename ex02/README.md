# Exercício 2 - Triagem de Faturamento

## 📌 Descrição
O programa realiza o cadastro de 5 funcionários, armazenando em vetores distintos o nome, o sexo e o salário de cada um.

Ao final, o sistema filtra e exibe apenas as funcionárias mulheres que ganham mais de R$ 5.000,00. A automação perfeita para mapear quem trabalha até tarde da noite para pagar o próprio café expresso de todas as manhãs e tem orçamento de sobra para não perder tempo chorando por quem não vale a pena.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um ambiente que suporte JavaScript e entrada de dados via `prompt`.
