# Exercício 3 - Extremos de Estatura

## 📌 Descrição
O programa permite cadastrar o nome e a altura de várias pessoas, armazenando os dados em vetores. O cadastro continua até que o usuário informe que não deseja adicionar novas pessoas.

Ao final, o sistema identifica e exibe a maior e a menor altura do grupo.
## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um ambiente que suporte JavaScript e entrada de dados via `prompt`.

## 📋 Exemplo de Saída

Resultados

Maior altura: 1.93m e pertence a Julian

Menor altura: 1.51m e pertence a Chloe
