# Exercício 1 - O Dono da Driver's License

## 📌 Descrição
O programa armazena a idade de 4 pessoas em um vetor através de um laço de repetição. 

Ao final, o sistema identifica e exibe a maior idade digitada. O filtro perfeito para descobrir quem no grupo finalmente já pode passar pelos subúrbios chorando porque finalmente conseguiu a permissão para dirigir, ou quem ainda é muito novo e está preso na fase dos *sour 17*.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um ambiente que suporte JavaScript e entrada de dados via `prompt`.

## 📋 Exemplo de Saída

Idades digitadas: 17, 19, 21, 15
Maior idade digitada: 21 anos.
